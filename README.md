# Pomodoro-Timer
A Pomodoro Timer desktop app built with Python and Tkinter to help manage focused work sessions and breaks.

🍅 Pomodoro Timer

A desktop Pomodoro Timer built with Python and Tkinter as part of Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp.

📌 About the Project

The Pomodoro Timer is a productivity application that helps users manage their study or work sessions by alternating between focused work periods and breaks.

✨ Features

- ⏱️ 25-minute work sessions.
- ☕ Short breaks between work sessions.
- 🌴 Long breaks after completing a number of work sessions.
- ✅ Visual indicators to track completed sessions.
- 🖥️ A graphical user interface built with Tkinter.

🛠️ Built With

- Python
- Tkinter

🚀 How to Run

1. Make sure Python is installed on your computer.

2. Clone this repository:
   
   git clone
https://github.com/pop239/Pomodoro-Timer.git
3. Navigate to the project folder.

4. Run the application:
   
   python main.py
